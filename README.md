# StaffSync

StaffSync is an HR demo for employee records, attendance, leave requests, announcements, training, and account sign-in.

- **Live demo:** https://staffsync-icdg.onrender.com
- **Project guide:** [docs/PROJECT_GUIDE.md](docs/PROJECT_GUIDE.md)
- **Stack:** Node.js, Express, MongoDB/Mongoose, HTML, CSS, and JavaScript

> Use synthetic data only. HR and manager accounts require private invitation codes; managers are not team-scoped.
